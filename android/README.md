# MokomailBrowser для Android

Нативный Android-браузер на Kotlin/Java + системный `WebView`, повторяющий интерфейс и
функции настольной версии MokomailBrowser (Electron).

> Важно: Electron **не запускается** на Android, поэтому это не тот же самый код, а
> полноценный нативный порт с тем же языком интерфейса, теми же цветами, логотипом и
> набором функций.

## Что реализовано

- Тёмная Material-тема, синий акцент, фирменный логотип (компас) — как в настольной версии.
- Омнибокс: поиск или адрес сайта (распознаёт домены автоматически).
- Вкладки: несколько страниц, список вкладок (как «Список вкладок» в Ctrl+Shift+A).
- Поисковые системы: Google, Яндекс, DuckDuckGo, Bing, Mail.ru, Википедия, своя ссылка.
- Домашняя страница как в приложении: логотип, поиск, «Часто посещаемые» с реальными иконками сайтов.
- Закладки и история (добавление, просмотр, удаление, очистка).
- Режим инкогнито (вкладка не попадает в историю).
- Настольная версия сайта (подмена User-Agent).
- Загрузки через системный DownloadManager.
- Поиск по странице, «Поделиться», экран «О браузере» (TikTok @mokomail, GitHub mokomail).
- Первоначальная настройка (выбор поисковой системы) при первом запуске.
- Настройки: поисковик, домашняя страница, блокировка всплывающих окон, история, очистка данных.

## Сборка

Нужны JDK 17, Android SDK (platform 34, build-tools 34.0.0) и Gradle 8.7.

```powershell
.\build.ps1                 # релизный APK
.\build.ps1 -Task :app:assembleDebug
```

Готовые APK появятся в `android/apk/`:

- `MokomailBrowser-release.apk` — релизный (подписан debug-ключом, годится для установки).
- `MokomailBrowser-debug.apk` — отладочный.

## Установка на телефон

1. Скопируйте APK на устройство.
2. Разрешите установку из неизвестных источников.
3. Откройте APK и установите.

Или через adb: `adb install android/apk/MokomailBrowser-release.apk`.
